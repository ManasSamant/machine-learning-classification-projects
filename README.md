# Machine Learning Classification Projects

A collection of three machine learning projects covering **deep learning, probabilistic classification, and predictive analytics**. The projects demonstrate the application of different machine learning techniques to image classification, text classification, and student dropout prediction.

## Projects

### 1. Fake Image Detection using CNN

A deep learning project that uses a **Convolutional Neural Network (CNN)** to classify images and identify potentially fake or AI-generated images.

**Technologies:**

* Python
* PyTorch
* Convolutional Neural Networks (CNN)
* Deep Learning
* Image Classification

**Files:**

* `Fake_Image_classifier_final...ipynb` — Jupyter Notebook containing the implementation and experiments.
* `fake_image_cnn.pth` — Trained PyTorch model.

---

### 2. Naive Bayes Text Classifier

A machine learning project implementing a **Naive Bayes classifier** for probabilistic text classification.

The project demonstrates the use of probabilistic machine learning techniques for processing and classifying textual data.

**Technologies:**

* Python
* Jupyter Notebook
* Naive Bayes
* Machine Learning
* Text Classification

**Files:**

* `NaiveBayes_assignment.ipynb` — Jupyter Notebook containing the implementation and analysis.
* `naiver_bayes_klassifizierer.py` — Python implementation of the classifier.

---

### 3. Student Dropout Prediction

A machine learning classification project focused on predicting whether a student is likely to **drop out of an educational programme** based on available student-related data.

The project covers data preparation, model training, classification, and evaluation.

**Technologies:**

* Python
* Scikit-learn
* Machine Learning
* Classification
* Predictive Analytics

**Files:**

* `_Projekt_2_student_drop_out_classifier.ipynb` — Jupyter Notebook containing the complete implementation.
* `best_model.pkl` — Saved trained machine learning model.

---
